# flag-git-2026

O repositório da turma do curso **Especializado Front-End Web Development** (FLAG, 2026/27), criado na sessão 3 do módulo 3 (Git e GitHub) para treinar o trabalho em equipa: um branch por pessoa, um Pull Request, uma revisão.

## Como participar

1. Aceitar o convite (github.com/JoaoGoncalves/flag-git-2026/invitations).
2. `git clone https://github.com/JoaoGoncalves/flag-git-2026.git`
3. `git switch -c feat/<o-vosso-username>`
4. Criar o ficheiro `formandos/<o-vosso-username>.md` com o modelo abaixo.
5. `git add formandos` · `git commit -m "feat: acrescenta a apresentação de <nome>"` · `git push -u origin feat/<o-vosso-username>`
6. No GitHub: **Compare & pull request** › **Create pull request**. Eu revejo e junto ao `main`.
7. `git switch main` · `git pull`

## O modelo

```markdown
# O vosso nome

- **De onde:** a vossa cidade
- **O que faço:** a vossa profissão ou área
- **O que quero fazer com Front-End:** uma frase
```

## A turma

As apresentações estão na pasta [`formandos/`](formandos/).
